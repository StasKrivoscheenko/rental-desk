# Облік оренди техніки

Внутрішня вебпрограма зі спільним реєстром оренд, обліковими записами працівників та окремим формуванням договору оренди й акта приймання-передачі.

## Установлення на серверному комп’ютері Windows

Потрібні Windows 10/11 або Windows Server, права адміністратора, Python 3.11 чи новіший та доступ до інтернету під час встановлення залежностей.

1. На робочому комп’ютері запустіть `powershell -ExecutionPolicy Bypass -File .\package_server.ps1`. Скрипт створить `RentalDesk-Server-Next-Install.zip` поруч із папкою програми. Перенесіть архів на сервер і розпакуйте його в окрему папку.
2. Відкрийте PowerShell **від імені адміністратора** у цій папці.
3. Запустіть майстер без зміни системної політики запуску скриптів:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install_server.ps1
   ```

4. Майстер встановить ізольоване Python-середовище, застосунок і початкові завдання планувальника. Сервер залишиться зупиненим, автозапуск і автоматичний бекап будуть вимкнені.
5. Відкрийте ярлик **RentalDesk - сервер** на робочому столі. У панелі введіть адресу сервера або виберіть IP цього пристрою, вкажіть порт і за бажанням увімкніть автозапуск та щоденний бекап. Натисніть «Зберегти налаштування», потім «Запустити».
6. Відкрийте адресу із панелі в браузері. На сторінці `/setup` створіть першого адміністратора, а потім додайте працівників.

Сервер слухає мережеві інтерфейси, а працівники заходять за вибраною IP-адресою або ім’ям, наприклад `http://192.168.1.25:5000`. Закріпіть адресу сервера в налаштуваннях мережі або використовуйте постійне DNS-ім’я. Не перенаправляйте порт програми з інтернету до локальної мережі.

Програма встановлюється до `C:\Program Files\RentalDesk`, а база, конфігурація й журнали зберігаються окремо у `C:\ProgramData\RentalDesk`. Сервер працює через Waitress як завдання Планувальника. Панель керування показує стан сервера та дає змогу запускати, перезапускати й зупиняти його.

## Резервні копії та відновлення

У панелі сервера можна задати час автоматичного резервного копіювання й увімкнути його. Копія створюється через SQLite backup API, перевіряється на цілісність і зберігається 30 днів. Якщо сервер вимкнений у запланований час, завдання запускається після наступного старту Windows. Адміністратор може будь-коли створити копію кнопкою на вкладці «Сервіс» або в панелі керування сервером. На вкладці «Сервіс» можна також вибрати копію й відновити базу: програма перевірить файл, попросить ввести `RESTORE` і збереже поточну базу окремою копією перед заміною. Для захисту від поломки самого диска виберіть папку на іншому диску або підключеному зовнішньому носії.

Після встановлення на спільному робочому столі з’явиться ярлик «RentalDesk - сервер». Панель показує стан сервера, керує його запуском/зупинкою, зберігає IP і порт, а також створює або змінює завдання автозапуску та резервного копіювання.

Щоб оновити вже встановлену програму, розпакуйте новий пакет у тимчасову папку й запустіть `update_server.ps1` від імені адміністратора. Сценарій збереже копію бази, замінить файли програми та перезапустить сервер, не змінюючи налаштування чи облікові записи.

Щоб відновити базу, запустіть PowerShell від імені адміністратора та виконайте:

```powershell
powershell -ExecutionPolicy Bypass -File "$env:ProgramFiles\RentalDesk\restore_backup.ps1"
```

Якщо вибрали іншу папку встановлення, вкажіть шлях до `restore_backup.ps1` у ній. Виберіть копію зі списку й підтвердьте дію словом `RESTORE`. Майстер зупинить серверне завдання, збереже поточну базу в резервні копії, перевірить вибраний файл, замінить базу й запустить сервер знову.

## Робочі функції

У реєстрі є пошук за номером договору, клієнтом і технікою та фільтри за статусом і строком повернення. Кнопка «Експорт CSV» завантажує весь список або саме відфільтровані результати у форматі, сумісному з Excel. Вкладка «Клієнти» автоматично збирає орендарів з договорів і показує їхні оренди та суму. Адміністратор може видалити помилковий запис; дія не має скасування, тому перед видаленням бажано створити копію. Збережену оренду можна редагувати; договір та акт формуються з її актуальних даних. Оновлений інтерфейс адаптується до мобільного екрана.

Інтерфейс програми українською. У документах можна відкрити окремо договір або акт, роздрукувати кожен чи зберегти в PDF через діалог друку, а також завантажити HTML-файл.
